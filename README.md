# solid-icons

> This README was generated by AI.

Source-only TSX fork of [`solid-icons`](https://github.com/x64Bits/solid-icons). Ships `md` and `ai` packs as plain `.tsx` — no build step, no `dist/`. Upstream's precompiled `.jsx` breaks Vite 8's SSR dep-optimizer on Cloudflare Workers; shipping TSX lets `vite-plugin-solid` handle it.

## Use

```json
"solid-icons": "github:KennanHunter/solid-icons#<sha>"
```

```tsx
import { MdFillLight_mode } from "solid-icons/md/MdFillLight_mode";
import { AiOutlineInfoCircle } from "solid-icons/ai/AiOutlineInfoCircle";
```

Grep `src/md/` or `src/ai/` for exact names.

## Refresh / add a pack

```bash
npm install --no-save solid-icons@latest
node scripts/port.mjs <pack> node_modules/solid-icons/<pack>/index.js
```

Add an `exports` entry for new packs. Don't hand-edit ported files.
